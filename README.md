# QIM Clothes Store 🛍️

Welcome to **QIM Clothes Store**, an online fashion store where customers can browse clothes, add products to a cart, and place orders through WhatsApp.

## Features

- Browse sample clothing products
- Search products
- Filter products by category
- Add products to shopping cart
- Increase or decrease quantity
- Remove products from cart
- Automatic total price calculation
- Customer checkout form
- Delivery location and notes
- WhatsApp ordering
- Responsive design for phones and computers

## Technologies

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start shopping.

## How to Place an Order

1. Choose a product.
2. Click **Add to Cart**.
3. Open the cart.
4. Select **Proceed to Checkout**.
5. Enter your name, phone number, and delivery location.
6. Review your order.
7. Click **Order via WhatsApp**.

## Adding Real Product Images

The website currently uses sample image placeholders.

Replace the sample image URL in `script.js` with your own image, for example:

```javascript
image: "images/black-tshirt.jpg"
```

Then create an `images` folder and put your product photos inside it.
